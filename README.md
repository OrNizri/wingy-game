# כנפיים 🐤

משחק דפדפן בסגנון "ציפור מעופפת" עם מערכת משתמשים (שם משתמש + סיסמה) ואפשרות כניסה עם Google.

## הרצה
```bash
python -m http.server 8765
```
ואז לפתוח את http://localhost:8765

## כניסה עם Google
יש להכניס OAuth Client ID בקובץ `config.js` (ההוראות בתוך הקובץ).

## שליטה
רווח / חץ למעלה / קליק / נגיעה — נפנוף.

> המשתמשים והשיאים נשמרים ב-localStorage של הדפדפן בלבד.
