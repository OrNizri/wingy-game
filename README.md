# כנפיים 🐤

משחק דפדפן בסגנון "ציפור מעופפת" עם מערכת משתמשים (שם משתמש + סיסמה) ואפשרות כניסה עם Google.

## הרצה
```bash
python -m http.server 8765
```
ואז לפתוח את http://localhost:8765

## כניסה עם Google
יש להכניס OAuth Client ID בקובץ `config.js` (ההוראות בתוך הקובץ).

## שליטה
- רווח / חץ למעלה / קליק / נגיעה — נפנוף
- P או Esc — הפסקה
- M — השתקת סאונד

## מה יש במשחק
- קושי שעולה בהדרגה (מהירות גבוהה יותר ופתח קטן יותר)
- מדליות: ארד (5), כסף (10), זהב (25), פלטינה (40)
- אפקטים קוליים שנוצרים בקוד, שיא אישי וטבלת שיאים

## אבטחה
- סיסמאות מוצפנות ב-PBKDF2-SHA256 (210,000 סבבים) עם salt אקראי לכל משתמש
- Content Security Policy שמאפשרת רק את קבצי המשחק ואת Google
- כל הנתונים נשמרים בדפדפן בלבד, ולכן אין הגנה מפני מי שיש לו גישה לאותו מחשב/דפדפן

> המשתמשים והשיאים נשמרים ב-localStorage של הדפדפן בלבד.
